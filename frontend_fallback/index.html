What this page is

A single-file placeholder so the server always answers at /. The real React/plain-HTML interface is built from docs/FRONTEND_SPEC.md, which lists every endpoint with a real example response from the seeded database.

Try the API now (everything below is live and offline)

  • /api/overview — KPIs, triage list, hotspots
  • /api/network — 98 nodes, 78 pipes, WQI per node
  • /api/air — NAQI per station + 24 h PM forecast
  • /api/land/reports — image reports, proximity score, water cross-link
  • /api/cases — the clustered cases (zone_3 is the hero)
  • /docs — interactive OpenAPI, or /openapi.json

The demo path the UI must support

  1. File a muddy-water complaint at a ward-3 building → POST /api/complaints
  2. Watch five complaints collapse into one case → POST /api/cluster/run
  3. Trace upstream to the shared cause → GET /api/trace/{case_id}
  4. Read the standard cited next to the breach → GET /api/cases/{id}
  5. Draft the advisory, approve it as a human → POST /api/cases/{id}/draft, PATCH /api/cases/{id}/status
  6. Forecast the chlorine crossing → GET /api/nodes/zone_5/forecast
Automated findings support human judgment. They are not official regulatory decisions. All data is a synthetic sample.
